# Две копии сайтов

## 1. «Рабочие руки Краснодар»

Откройте файл `site-workers/index.html` в браузере.

## 2. Рабочий дом «Опора»

Откройте файл `site-opora/index.html` в браузере.

Обе копии адаптированы под компьютер и телефон. Фотографии второго сайта сохранены локально.

Формы отправляют заявки в Telegram-чат через серверный обработчик. Телефон обязателен, имя можно не указывать. Секретный токен хранится в файле `.env`, который исключён из Git.

Для запуска первого сайта: `npm run start:workers`.

Для запуска второго сайта: `npm run start:opora`.
